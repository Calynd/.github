# Calynd

**Beyond Conventional Computing**

## About

Calynd is an independent software development organization focused on creating software, operating systems, development tools and experimental technologies.

We believe in independent development, thoughtful engineering and exploring new possibilities in computing.

## Projects

Our projects cover different areas of software development, from operating system experimentation to development tools and utilities.

## Philosophy

- **Independence** — Developing technology on our own terms.
- **Experimentation** — Exploring ideas beyond conventional approaches.
- **Simplicity** — Valuing clear, purposeful engineering.
- **Open Development** — Sharing projects and progress with the community.
